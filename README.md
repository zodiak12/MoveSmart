# 🚚 MoveSmart — Умный сервис организации переезда

## 1. Описание проекта
Клиент купил или снял квартиру, и наступает хаос: нужно найти грузчиков, транспорт, заказать уборку, не забыть про страховку и запомнить десятки дел — от передачи показаний счётчиков до поиска ближайшей аптеки. Каждая услуга требует отдельного поиска и проверки, отнимая недели и нервы. 

**MoveSmart** — это веб-платформа, которая объединяет проверенных партнёров и даёт клиенту единый интерфейс для планирования и управления всеми этапами переезда. Сервис позволяет сконструировать оптимальный набор услуг, отслеживать их выполнение на одном таймлайне и получить персональный чек-лист новосёла с привязкой к новому адресу.

**Целевая аудитория:**
- **Клиенты**, которые хотят переехать без стресса и потери времени.
- **Партнёры-исполнители** (грузоперевозки, клининг, страхование, интернет-провайдеры), желающие получать заказы из надёжного источника.
- **Риелторы**, которые могут предоставить сервис клиенту сразу после сделки, повышая лояльность и получая дополнительный канал взаимодействия.

## 2. User Stories
- Как **клиент**, я хочу **пройти пошаговый конструктор переезда**, чтобы **получить предложение из оптимального набора услуг**.
- Как **клиент**, я хочу **видеть единый календарь со всеми моими заказами**, чтобы **контролировать логистику дня переезда**.
- Как **клиент**, я хочу **получить «чек-лист новосёла» с привязкой к моему новому адресу**, чтобы **ничего не забыть и быстро освоиться на новом месте**.
- Как **клиент**, я хочу **оставить отзыв о работе партнёра только после завершения заказа**, чтобы **помочь другим пользователям с выбором**.
- Как **партнёр**, я хочу **видеть список новых заказов и управлять их статусами**, чтобы **эффективно планировать свою работу**.
- Как **партнёр**, я хочу **добавлять и редактировать свои услуги**, чтобы **предлагать актуальные позиции клиентам**.
- Как **риелтор**, я хочу **видеть список клиентов, которым я отправил приглашение в сервис, и текущий этап их переезда**, чтобы **вовремя предложить помощь**.

## 3. Функциональные требования (MoSCoW)
**Must have (MVP)**:
- Регистрация и авторизация, роли user/partner/agent.
- Создание и редактирование плана переезда с адресами и датой.
- Каталог услуг партнёров с поиском и фильтрацией по категориям и цене.
- Создание заказа услуги и привязка его к плану переезда.
- Статусная модель заказа: created → accepted → in_progress → completed / cancelled.
- Единый таймлайн переезда, где отображаются все заказы.
- Базовый чек-лист для новосёла (CRUD пунктов).
- Email-уведомления о подтверждении и изменении статуса заказа.

**Should have**:
- Личный кабинет клиента с историей переездов.
- Рейтинг и отзывы партнёров.
- Дашборд партнёра (статистика, слоты).
- Пагинация на всех списках.

**Could have**:
- Интеграция с Yandex Maps для геопривязки чек-листа (ближайшие МФЦ, поликлиники).
- Имитация отправки приглашения от риелтора (интеграция с CRM «Этажей»).
- Drag-and-drop в таймлайне для изменения порядка услуг.
- Административная панель для управления партнёрами.

**Won't have (на данный момент)**:
- Полноценная онлайн-оплата.
- Реальное API партнёров, мобильное приложение.

## 4. Список ключевых экранов
1. **Главная / Лендинг сервиса** — информация о возможностях, готовые пакеты услуг, кнопка «Организовать переезд».
2. **Конструктор переезда** — пошаговая форма: адреса, дата, состав семьи → выбор категорий услуг → итоговая сводка.
3. **Каталог услуг** — карточки партнёров с фильтрацией по категориям, поиском, рейтингом, ценой. Карта с метками (опционально).
4. **Таймлайн «Мой переезд»** — календарный вид с заказами, статусами и возможностью отмены/редактирования.
5. **Чек-лист новосёла** — список задач, сгруппированных по категориям, с чекбоксами и подсказками.
6. **Личный кабинет клиента** — профиль, история переездов, избранные услуги, смена пароля.
7. **Дашборд партнёра** — заказы на сегодня, загруженность, управление услугами.
8. **Список заказов (для партнёра)** — таблица с возможностью изменить статус.
9. **Мои клиенты (для риелтора)** — список клиентов со статусами их переездов.

## 5. Список основных сущностей и связей

| Сущность | Поля |
|---|---|
| **User** | id, name, email, password_hash, phone, role (user/partner/agent/admin), created_at |
| **Move** | id, user_id (FK), address_from, address_to, move_date, status (draft/planned/active/completed) |
| **ServiceCategory** | id, name («Грузчики», «Клининг», «Интернет») |
| **Partner** | id, user_id (FK, если партнёр — пользователь), company_name, category_id (FK), description, rating, contacts |
| **PartnerService** | id, partner_id (FK), title, price, duration_hours, options (JSON) |
| **Order** | id, move_id (FK), partner_service_id (FK), scheduled_date, status (created/accepted/in_progress/completed/cancelled) |
| **MoveChecklistItem**| id, move_id (FK), task_text, category (административные/бытовые/прочее), is_completed (bool), hint |
| **Review** | id, order_id (FK), user_id (FK), rating (1-5), comment, created_at |
| **Notification** | id, user_id (FK), type, message, is_read (bool), sent_at |

**Ключевые связи:**
- Пользователь (1) — (m) Переезд
- Пользователь (1) — (m) Отзыв
- Переезд (1) — (m) Заказ
- Переезд (1) — (m) Чек-лист пункт
- Партнёр (1) — (m) Услуга партнёра
- Услуга партнёра (1) — (m) Заказ
- Заказ (1) — (0..1) Отзыв (возможен только после завершения)
